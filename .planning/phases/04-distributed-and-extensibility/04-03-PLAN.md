# HP-09 — Skill package and execution hardening

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Phase:** 4 — Distributed runtime and extensibility
**Package:** HP-09
**Requirements:** SKIL-01, SKIL-02
**Depends on:** HP-03, HP-05 (parallel with HP-08)
**Goal:** Signed skill manifest; JV and Claude `SKILL.md` remain the only forms; selectable isolation backends; stage per NativeCaller + snapshot with deterministic cleanup.

**Architecture:** Keep ADR-0017 two specs. `SubprocessExecutor` stays development-only containment — document that clearly. Untrusted script skills refuse unless an approved isolation backend is configured.

Staging today: `code_execution_action.stage_skill` into per-user sandbox. Key staging by snapshot digest so a revoked/changed skill cannot run stale.
